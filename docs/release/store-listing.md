# Play Store listing draft

**App name:** MindForge 101
**Short description (80):** Offline brain training: 60 quick games for memory, focus, logic and speed.
**Full description:**
MindForge 101 is a free, offline brain-training app with about 60 short games across 10 categories: memory, attention, logic, math, language, spatial reasoning, problem solving, visual perception, speed, and executive function.

- Adaptive difficulty (10 levels per game) that adjusts to how you play
- Daily Brain Mix of five games
- XP, ranks from Beginner to Mind Forge, streaks, and achievements
- Multiple local profiles
- Large-text and reduce-motion options; never relies on color alone
- No ads, no purchases, no account, works fully offline

MindForge 101 is for fun and personal practice. It is not a medical product.

**Category:** Puzzle (or Education) · **Content rating:** Everyone
**Data safety:** No data collected, no data shared. No INTERNET permission.
